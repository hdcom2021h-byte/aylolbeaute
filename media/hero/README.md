# فيديو الواجهة الرئيسية

ضعي الفيديو في هذا المجلد باسم `hero.mp4`، ليصبح مساره:

`media/hero/hero.mp4`

يفضّل فيديو عمودي بصيغة MP4 وترميز H.264، قصير ومضغوط لسرعة التحميل.
سيظهر داخل إطار الصورة الحالية ويعمل دون صوت مع التكرار وأزرار التحكم.
عند تفعيل تقليل الحركة في الجهاز، يبدأ التشغيل بالضغط يدويًا.
تظل الصورة الحالية ظاهرة إذا لم يوجد الفيديو أو تعذّر تحميله.

لتغييره مستقبلًا، استبدلي `hero.mp4` ثم حدّثي الصفحة بـ Ctrl + F5.
