# صور معرض أيلول

ضعي الصور داخل المجلد المناسب: `Makeup` للميكب، `Hair` للشعر، `Brides` للعرائس، و`Nails` للأظافر.
الصيغ المدعومة: JPG وJPEG وPNG وWebP وAVIF. يُفضّل ضغط الصور قبل إضافتها.
يمكن أيضًا إضافة فيديو MP4 أو WebM داخل مجلد الفئة؛ سيظهر ببطاقة تشغيل ونافذة تكبير. لفيديو عناية الشعر استخدمي مجلد `Hair`.

بعد إضافة الصور أو حذفها، شغّلي من مجلد الموقع:

```powershell
python media/gallery/update-gallery.py
```

ارفعي الصور وملف `gallery.js` المحدّث مع الموقع. لا يحتاج الموقع إلى Python أثناء التصفح.
يمكن تعديل النص البديل لكل صورة في `gallery.js` يدويًا؛ إعادة تشغيل الأمر تعيد توليد النصوص.

للحفاظ على ترتيب الصور وعناوينها وسطوع عرضها عند التحديث، عدّلي `photo-settings.json`.
`order` يحدد الترتيب، و`alt` وصف الصورة، و`brightness` سطوع العرض (1 هو الأصل).
هذه إعدادات عرض فقط؛ لا تغيّر ملفات الصور الأصلية.
